================================================================================

2.1 MarketSnapshot:
- timestamp: float (epoch milliseconds)
- latest_price: float
- best_bid: float, best_ask: float
- spread: float (best_ask - best_bid)
- spread_pct: float ((spread / latest_price) * 100)
- feed_latency_ms: float (processing timestamp - exchange tick timestamp)
- orderbook_depth: dict of 50 bid levels and 50 ask levels (price -> size)
- candle_buffers: map of 11 timeframes -> rolling OHLCV ring buffers
- trade_velocity: float (trades per second)
- cvd: float (Cumulative Volume Delta)
- oi_zscore: float (Derivatives Open Interest rolling Z-score)

2.2 FeatureVector:

3. SENSORY INGESTION & VECTORIZED PERCEPTION (ORGAN 1 & 2)
===============================================================================

3.1 11-Timeframe Ring Buffers:
The Sensory Organ maintains rolling deque buffers of maximum 300 bars across 11 horizons:
Horizons = [1s, 1m, 3m, 5m, 15m, 30m, 1h, 2h, 4h, 6h, 1D]
- Ticks aggregate continuously without thread sleep or polling lag.
- Seeding: On cold start, the engine queries OKX REST `/api/v5/market/candles` to backfill
  100 bars for all 11 timeframes, making indicators active instantly upon boot.

3.2 3-Snapshot Anti-Spoofing Order Book Filter:
To eliminate phantom orders placed by algorithmic spoofers, the L2 book updates maintain a
3-snapshot FIFO queue:
- A bid or ask order is only considered valid institutional depth if it persists across
  all 3 consecutive snapshots. Transient winks (<50ms) are filtered to zero.
- Distance-weighted volume:
  w_i = exp(-40.0 * (|price_i - mid_price| / mid_price))
- tanh-smoothed depth imbalance:
  tanh_imbalance = tanh(3.0 * ((sum(bid_vol * w_bid) - sum(ask_vol * w_ask)) /
                               (sum(bid_vol * w_bid) + sum(ask_vol * w_ask))))

3.3 Real-Time Institutional Absorption Index (Ai):
Measures aggressive market sells hitting passive limit bids at support:
  Ai = (Taker_Sell_Volume / max(|Price_Drop|, 0.5)) * log(1 + Bid_Depth)
  - Ai > 15.0: Whales are aggressively absorbing the dip with resting limit walls.
  - Ai < 3.0: Thin order book, sellers are slicing through with zero absorption.

3.4 Structural Multi-Screen Boundaries:
To prevent sub-minute noise candles from acting as fake barriers:
- Structural horizons = {"5m", "15m", "30m", "1h", "2h", "4h", "6h", "1D"}.
- Upper and Lower Bollinger Bands (%B, Bandwidth 2.0 std) from structural horizons
  are pooled with macro swing highs/lows.
- Sub-minute bands (1s, 1m, 3m) are strictly excluded from structural resistance pools.

4. THE MIND: EXPLICIT BELIEF SYSTEM & ADAPTIVE HURDLES (ORGAN 3)
================================================================================

The Mind does not use rigid if-else geometric boxes. It computes a continuous mathematical
vector field representing directional flow, signal agreement, and urgency, augmented by an
Explicit Persistent Belief System and Bounded Adaptive Confidence Hurdles:

4.1 Trend Strength:
Evaluated across 5m, 15m, and 1h horizons:
  ts_5m  = (EMA_9(5m)  - EMA_21(5m))  / Price
  ts_15m = (EMA_9(15m) - EMA_21(15m)) / Price
  ts_1h  = (EMA_9(1h)  - EMA_21(1h))  / Price
  trend_strength = 0.40 * ts_5m + 0.40 * ts_15m + 0.20 * ts_1h

4.2 Cross-Screen Indicator Directional Entropy:
Quantifies indicator conflict across all timeframes:
  Entropy = - sum(p_i * log2(p_i)) / log2(3)
  - Entropy = 0.0: Total alignment across all 11 horizons.
  - Entropy = 1.0: Total signal conflict (random chop).

4.3 Continuous Raw Edge Equation:
Combines multi-scale trend, order book imbalance, whale absorption, and tape flow:
  trend_term = tanh(400.0 * trend_strength)
  imb_term   = tanh_imbalance
  abs_term   = min(Ai / 20.0, 1.0)
  flow_term  = +0.5 if (CVD > 0 and Trade_Velocity > 5.0) else (-0.3 if CVD < 0 else 0.0)
  entropy_penalty = 0.15 * Entropy

  Raw_Edge = (0.35 * trend_term) + (0.25 * imb_term) + (0.20 * abs_term) + (0.20 * flow_term) - entropy_penalty
  Edge = clamp(Raw_Edge, -1.0, 1.0)

4.4 Component 5: Explicit Belief System with Temporal Hysteresis:
To prevent sub-second indicator flickering from triggering false entries, the Mind maintains
a persistent internal `BeliefState` across ticks:
1. Exponential Smoothing (Decay Rate lambda = 0.85):
   bias_t = lambda * bias_(t-1) + (1.0 - lambda) * Edge_t
   entropy_ema_t = lambda * entropy_ema_(t-1) + (1.0 - lambda) * Entropy_t
2. Polarity Persistence Tracking:
   - If sign(bias_t) == sign(bias_(t-1)) and |bias_t| >= 0.08:
     persistence_ticks = persistence_ticks + 1
   - Else:
     persistence_ticks = 1
3. Anti-Flicker Conviction Multiplier:
   pers_mult = min(1.0, 0.70 + 0.15 * min(persistence_ticks, 2))
   Conviction = (|bias_t| / (1.0 + entropy_ema_t)) * pers_mult
   Guarantees that an isolated 1-tick flash spike cannot trigger full position sizing.
4. Regime Belief Classification:
   - `BULL_ACCELERATION`: bias_t > 0.20 and (is_balloon_expanding or urgency >= 0.20)
   - `BEAR_PRESSURE`: bias_t < -0.20
   - `CHOP_COMPRESSION`: is_slow_market or entropy_ema_t >= 0.65
   - `NEUTRAL_WAIT`: Balanced transitional condition

4.5 Component 3: Adaptive Confidence Thresholds based on Regime:
Replaces fixed hurdle rules with dynamic hurdles responsive to market conditions:
- TREND Regime: theta_conf = 0.50 (clean momentum flow, enter early into waves)
- BALANCED / RANGE Regime: theta_conf = 0.65
- CHOP / HIGH ENTROPY Regime: theta_conf = 0.80 (demands overwhelming institutional conviction before risking capital)

4.6 Component 7: Intuition Tripwires:
Non-linear microstructure modifiers (modifiers only: +-0.05, never opens trades directly):
- Tape acceleration burst (>8.0 trades/sec with positive CVD): +0.05 confidence
- Institutional resting absorption wall (Ai > 20.0): +0.05 confidence
- Spread inflation (>0.15%): -0.05 confidence
- Aggressive taker dumping: -0.05 confidence

4.7 Component 4: Mandatory Net Expected Value Gate:
  Projected_Move = max(Nearest_Structural_Resistance - Price, 1.2 * Composite_ATR)
  Projected_Gross_Pct = (Projected_Move / Price) * 100
  Estimated_Slippage = max(0.02%, (Spread_Pct / 2.0) * 1.25)
  Net_EV_Pct = Projected_Gross_Pct - OKX_Roundtrip_Fee (0.20%) - Estimated_Slippage

  - Mandatory Gate: If Net_EV_Pct <= 0.05% or (immediate_runway < adaptive_runway and macro_runway < 1.50):
    Mind unconditionally issues `WAIT_IN_CASH`. Zero bypass loopholes permitted!
  - Momentum Ignition Trigger: Requires effective_edge >= 0.15, effective_urgency >= 0.15,
    tuned_confidence >= regime_conf_hurdle, and Belief State != "CHOP_COMPRESSION".
  - Dip Absorption Turn Trigger: If price testing support with Ai > 12.0, tanh_imb >= 0.0, and runway >= theta_runway:
    Mind proposes `ENTER_CORE_LOT_1` targeting structural resistance.

5. THE CONSCIENCE: DETERMINISTIC RISK INVARIANTS & GOVERNOR ORGANS (ORGAN 4)
================================================================================

The Conscience executes deterministic invariant checks and governance rules on every proposed TradeIntent:

5.1 Component 1: Setup Performance Governor (SetupHealth):
Monitors rolling 20 closed trades for each setup name (MACRO_BALLOON_BREAKOUT, DIP_ABSORPTION_TURN):
- Calculates rolling win rate, average net PnL, and health score in [0.0, 100.0].
- 5 Contiguous Half-Open Health Tiers:
  * [80.0, 100.0]: Pristine -> 100% sizing, +0.00 hurdle modifier, active
  * [60.0, 80.0): Healthy  -> 75% sizing, +0.00 hurdle modifier, active
  * [40.0, 60.0): Degraded -> 50% sizing, +0.05 hurdle modifier, active
  * [20.0, 40.0): Stressed -> 25% sizing, +0.10 hurdle modifier, active
  * [0.0, 20.0): Disabled -> 0% sizing, unconditional REJECT

5.2 Component 5: Dynamic Thesis Failure Counter & Dual-Class Cooldown:
The Single Source of Truth for setup-level cooldown governance and thesis protection.
A. Class B: Loss-Based Cooldown (Immutable Timer):
   - Triggered upon consecutive trade losses on that setup.
   - Dynamic duration formula:
     Candidate = clamp(3.0m * M_loss * M_health * M_entropy, 3.0m, 45.0m)
     Final_Duration = max(Candidate, LossFloor)
   - Graduated Loss Multipliers & Hard Minimum Loss Floors:
     * 1 loss:  M_loss = 1.0x, minimum floor = 3.0 minutes
     * 2 losses: M_loss = 2.5x, minimum floor = 8.0 minutes
     * 3+ losses: M_loss = 6.0x (+2.0x per additional loss), minimum floor = 20.0 minutes
   - Setup Health Multiplier (M_health):
     * [0.0, 20.0): 1.8x | [20.0, 40.0): 1.5x | [40.0, 60.0): 1.2x | >= 60.0: 1.0x
     * Historical setup health CANNOT reduce cooldown duration below the loss floor.
   - Market Entropy Multiplier (M_entropy):
     * If entropy >= 0.70: 1.5x multiplier applied to candidate duration; else 1.0x.
   - Invariant: Zero early release permitted on Class B loss locks. Timer must run in full.

B. Class A: Market-Condition Gate (Condition-Based, Zero Timers):
   - High entropy (entropy >= 0.70): Blocks entries with WAIT_HIGH_ENTROPY until structure forms.
   - Moderate entropy (entropy >= 0.65) or degraded health (< 60.0): REDUCE_SIZE_AND_CONFIRM (50% size, +0.05 hurdle).
   - Early release permitted ONLY when:
     1. Entropy drops strictly below 0.40, AND
     2. Validated trend transition occurs: normalized tanh(400.0 * trend_strength) >= 0.15, AND
     3. Original setup entry conditions are reconfirmed.
   - Early release NEVER overrides a Class B loss cooldown, setup disablement, or account drawdown lock.

C. State Persistence & Auditability:
   - Cooldown state (consecutive_failures, disabled_until) is serialized atomically via export_state() / import_state() into bot_state.json across restarts.
   - Cooldown blocks new entries and scale-ins, but NEVER prevents risk-reducing exits (CUT_THESIS_INVALIDATED).
   - Hard safety invariants (kill switch, execution lock, daily drawdown breach) always take priority.

5.3 Component 8: Conscience Escalation Gate:
Tracks portfolio-wide consecutive losses across the account:
- When 3 or more consecutive losses occur, temporarily raises required entry confidence by +10% to +15% until recovery.

5.4 Component 6: Lightweight Analytical Stress Engine:
Evaluates instantaneous market shock tolerance without Monte Carlo overhead:
- Spread inflation shock: If spread_pct > 0.20% -> REJECT.
- Liquidity vacuum: If bid_depth < 30% of normal baseline -> REJECT.
- Adverse price drop to stop loss calculated analytically.

5.5 Invariant 5: Noise-Immune Floor Calculation:
Stop loss is mathematically anchored outside sub-minute ATR noise:
  Raw_Risk = max(Price - Nearest_Support, 0.0) + (0.5 * Composite_ATR)
  Clamped_Risk = min(max(Raw_Risk, 0.8 * Composite_ATR), 2.0 * Composite_ATR)
  Approved_Stop = Price - Clamped_Risk
Stop loss is guaranteed to sit strictly below actual entry fill price.

5.6 Invariant 6: Anti-Churn / Post-Stop Clearance:
If a previous trade was stopped out at price P_cut, the Risk Gate unconditionally vetoes
any breakout re-entry proposed at or below P_cut. Eliminates false-breakout churn.

5.7 Invariant 7: In-Situ Memory Soft Stop (Wick-Sweep Defense):
When market price touches the invalidation floor:
- Conscience audits real-time L2 book depth:
  If tanh_imbalance > 0.15 or Absorption_Index > 15.0:
  The cut proposal is VETOED and overridden to `HOLD_POSITION`. Whale limit bids are
  absorbing the sweep.
- If bids collapse (tanh_imbalance <= 0.0 and Ai < 5.0): Structural breakdown confirmed.
  `CUT_THESIS_INVALIDATED` is approved immediately.
- Hard Backstop: If price pierces floor by > 0.8 * Composite_ATR, emergency cut triggers
  unconditionally to preserve capital.

5.8 Invariant 8: Composite Dynamic Sizing & Shadow Self:
Composite size factor combines volatility regime, stress clamp, governor health, and failure penalty:
  Composite_Size = Size_Factor * Governor_Size_Mult * Failure_Penalty (clamped in [0.10, 1.0])

10. DEATH PROTOCOL & REBIRTH CYCLE
================================================================================

10.1 Death Protocol (Emergency Hard Stop):
- Triggers on: Hard account capital breach (e.g. -5.0%), persistent WebSocket crash (>60s),
  or unauthorized credential tamper.
- Execution sequence:
  1. Freeze: Immediately halt all new intent generation.
  2. Cancel: Atomic call to OKX REST `DELETE /api/v5/trade/cancel-all-after` and open orders.
  3. Flatten: Market sell open spot position if volatility is expanding.
  4. Lock: Write emergency crash dump to disk.
  5. Sleep: Terminate loop and send high-priority Telegram alert.

10.2 Rebirth Cycle:
- Supervised restart sequence:
  1. Purge: Archive corrupted state files to `archive_legacy_trades/`.
